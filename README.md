# Md Fahim Ahmed — Graphic Designer Portfolio

Phase 1: static frontend and admin dashboard UI. Backend integrations are intentionally deferred to Phase 2.

## Run
Serve this folder with any static web server or open `index.html` in a modern browser.

## Structure
- `index.html` — public portfolio
- `admin/index.html` — admin dashboard prototype
- `assets/css/styles.css` — responsive design system
- `assets/js/main.js` — public interactions
- `assets/js/admin.js` — admin UI interactions

All project cards and testimonials are clearly marked as demo placeholders, not real client work.
